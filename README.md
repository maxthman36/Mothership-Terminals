# Dream Terminals — GitHub Pages

Player-facing campaign terminals for the Mothership bounty-hunting campaign.
Built by `../build-site.sh` — do not edit files here directly; edit the
canonical copies in the parent folder and re-run the script.

## Publish

1. Create a **public** repo (e.g. `dream-terminals`).
2. Push the contents of this folder to `main`.
3. Repo Settings → Pages → Deploy from a branch → `main` → `/(root)`.
4. Live at `https://<you>.github.io/dream-terminals/`.

## Warden screen

`Session1-Warden-Screen.html` is deliberately NOT published — it contains
campaign spoilers. Keep it local, or host it separately behind access control.
